# EduSite Pro V2 Working
1. Run `database/supabase.sql` in Supabase SQL Editor.
2. Upload all extracted files to the ROOT of the GitHub repository.
3. Enable GitHub Pages from branch `main` and folder `/ (root)`.
4. Register an owner account, login, then create School Profile.
5. Add Team and Forms, then publish the Public Website.

Important: This V2 fixes the previous issue where dashboard pages were only static placeholders.
