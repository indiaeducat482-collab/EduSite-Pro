# EduSite Pro

School & Institute Website Builder + Owner Dashboard + Admin Panel.

## Setup
1. Run `database/supabase.sql` in Supabase SQL Editor.
2. Open `assets/js/supabase-config.js`.
3. Paste your Supabase URL and Publishable Key.
4. Upload the project to GitHub Pages or another static hosting service.
